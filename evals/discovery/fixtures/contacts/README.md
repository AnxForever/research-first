# Contacts demo

A small local contact list for a team. All names and addresses are synthetic.
Open `index.html`, or run `python -m http.server 4421 --bind 127.0.0.1` here.

The project uses plain HTML, CSS and JavaScript. There is no backend or account.
Contacts currently live only in the page session. Preserve the existing list and
keep the result runnable locally; no external service is needed. A typical input
is in `example.csv`.
